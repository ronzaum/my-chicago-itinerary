The following fonts in this pack are derived works of the TeX Gyre collection
(GUST e-foundry: Boguslaw Jackowski and Janusz M. Nowacki), distributed under
the GUST Font License (see GUST-FONT-LICENSE.txt). As the licence requests,
the derived fonts and files have been renamed:

  TeX Gyre Termes Regular  ->  FOS Editorial Serif Recon Regular   (FOSEditorialSerifRecon-Regular.*)
  TeX Gyre Termes Italic   ->  FOS Editorial Serif Recon Italic    (FOSEditorialSerifRecon-Italic.*)
  TeX Gyre Heros Regular   ->  FOS Editorial Grotesk Recon Regular (FOSEditorialGroteskRecon-Regular.*)
  TeX Gyre Cursor Regular  ->  FOS Elite Mono Recon Regular        (FOSEliteMonoRecon-Regular.*)
  TeX Gyre Cursor Italic   ->  FOS Elite Mono Recon Italic         (FOSEliteMonoRecon-Italic.*)

Modifications:
  Serif and Grotesk: renamed; vertical metrics unified (ascender 860, descender -240,
  typo metrics flagged); features reduced to kern and liga; no outline changes.
  Elite Mono: renamed; outlines condensed to 74 percent, thickened (15.5 units per side,
  plus 6 units per side horizontally), round dots replaced by squares, W and w rebuilt,
  advance width 444; glyph set reduced to Latin, Latin-1, Latin Extended-A, punctuation
  and symbols (404 glyphs); features removed.

The original manifests and readmes of the base fonts are included alongside this file.
